# Gothic 1 Remake — взлом сундуков

Веб-калькулятор мини-игры взлома сундуков из Gothic 1 Remake (пластины и штыри).
Оформлен в стиле игры: тёмная тема «камень/сталь/золото» и светлая «состаренный пергамент».

**Открыть онлайн:** https://perf769.github.io/plates-solver/

## Правила игры

- Несколько пластин (по умолчанию 6), в каждой 7 отверстий.
- В одном из отверстий стоит штырь; он «поднят» только в центральном **4-м** отверстии.
- Цель — собрать все пластины так, чтобы у каждой штырь оказался в 4-м отверстии.
- Пластины связаны односторонними связями:
  - **напрямую (→)** — связанная пластина двигается в ту же сторону;
  - **реверсивно (⇄)** — связанная двигается в обратную сторону.
- Если штырь у края (1 или 7), ход, выталкивающий его за пределы (в том числе через связь), запрещён.
- В самой игре пластины двигаются клавишами **A** (влево) и **D** (вправо) — шаги в решении подписаны этими клавишами.

## Как пользоваться

1. Выбери количество пластин (степпер «− N +»).
2. Отметь связи в таблице (клик по клетке: пусто → **→** → **⇄** → пусто).
3. Задай начальное положение штыря для каждой пластины.
4. Нажми плавающую кнопку **«Решить»** — приложение выдаст минимальное по числу ходов решение и трассировку.
5. Клик по шагу отмечает его выполненным (следующий подсвечивается).
6. **«Скопировать шаги»** копирует решение простым списком.

Дополнительно: переключатель светлой/тёмной темы, сохранение именованных уровней
с поиском, плавающая кнопка сброса. Настройки и уровни хранятся в браузере (localStorage).

## Файлы

- [`index.html`](index.html) — всё приложение (один файл, без зависимостей).
- [`solve.py`](solve.py) — тот же решатель на Python (BFS), для проверки в консоли.

## Как работает решатель

Поиск в ширину (BFS) по состояниям: одно состояние — позиции всех пластин,
один ход — сдвиг выбранной пластины на N отверстий с учётом связей.
Находит решение с минимальным числом ходов. Правила фиксированы: 7 отверстий, центр — 4-е.
