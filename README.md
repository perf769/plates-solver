# Решатель мини-игры с пластинами

Веб-калькулятор для мини-игры с пластинами и штырями.

**Открыть онлайн:** https://perf769.github.io/plates-solver/

## Правила игры

- Несколько пластин (по умолчанию 6), в каждой 7 отверстий.
- В одном из отверстий стоит штырь; он «поднят» только в центральном **4-м** отверстии.
- Цель — собрать все пластины так, чтобы у каждой штырь оказался в 4-м отверстии.
- Пластины связаны односторонними связями:
  - **п (напрямую)** — связанная пластина двигается в ту же сторону;
  - **р (реверсивно)** — связанная двигается в обратную сторону.
- Если штырь у края (1 или 7), ход, выталкивающий его за пределы (в том числе через связь), запрещён.

## Как пользоваться

1. Выбери количество пластин (степпер «− N +»).
2. Отметь связи в таблице (клик по клетке: пусто → **п** → **р** → пусто).
3. Задай начальное положение штыря для каждой пластины.
4. Нажми **«Решить»** — приложение выдаст минимальное по числу ходов решение и трассировку.
5. Кнопка **«Скопировать шаги»** копирует решение простым списком.

Настройки сохраняются в браузере (localStorage).

## Файлы

- [`index.html`](index.html) — всё приложение (один файл, без зависимостей).
- [`solve.py`](solve.py) — тот же решатель на Python (BFS), для проверки в консоли.

## Как работает решатель

Поиск в ширину (BFS) по состояниям: одно состояние — позиции всех пластин,
один ход — сдвиг выбранной пластины на N отверстий с учётом связей.
Находит решение с минимальным числом ходов. Правила фиксированы: 7 отверстий, центр — 4-е.
